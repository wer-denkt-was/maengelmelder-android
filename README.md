# Mängelmelder Android Library

An Android library module for reporting municipal defects ("Mängel"), built by [WDW](https://werdenktwas.de) and used in production by several German municipalities. You can incorporate it into your own Android application.

See the [iOS counterpart](https://github.com/wer-denkt-was/maengelmelder-ios) for the equivalent Swift package.

## Getting started

See [`maengelmelder/README.md`](maengelmelder/README.md) for integration instructions, and:

* [`maengelmelder/readme_settings.md`](maengelmelder/readme_settings.md) — configuration reference
* [`maengelmelder/readme_styling.md`](maengelmelder/readme_styling.md) — styling/customization guide
* [`maengelmelder/readme_api.md`](maengelmelder/readme_api.md) — using the API request classes directly
